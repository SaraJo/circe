# README artwork

`circe-header.png` is an original AI-generated editorial illustration created
for Circe on 2026-09-26 with the image-generation tool. The characters are
original concepts, not portraits of existing fictional characters or a
screenshot of the application. The direction was a warm pixel-art wordmark and
a crew in desktop conversation windows, using Circe's cream, peach, and sage
palette. No StarNet artwork was used as an input or copied into this repository.

`download-macos.svg` and `download-windows.svg` are locally authored vector
buttons. Their labels identify the supported architecture and beta status;
the README supplies the destination links.

The desktop screenshots and demo recording are user-provided views of Circe
in use. Documentation artwork is separate from runtime avatar sourcing.
