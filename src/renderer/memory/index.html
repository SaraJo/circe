Keep it on this machine

Extraction and embeddings use local Ollama models. Saved facts stay in a local SQLite database. Relevant facts are included in messages to your configured Hermes model.

Set up local models

Install and start Ollama from ollama.com, then download the two models in Terminal. The defaults use:

ollama pull qwen3:4b
ollama pull embeddinggemma

You can choose other installed local models above. Cloud models are refused. Changing the embedding model rebuilds saved vectors and can take a moment.
